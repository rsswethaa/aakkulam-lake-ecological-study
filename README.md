# Ecological Study of Aakkulam Lake

> **Portfolio reconstruction:** This repository is a modern documentation and data-analysis rebuild based on the verified research project description in my CV. It is not presented as the exact archived files from the original submission.

A research-oriented portfolio project examining urban pollution pressures and ecological sustainability around Aakkulam Lake through structured field observations and reproducible data analysis.

## Project focus
- Environmental field observations
- Urban pollution indicators
- Water and habitat condition tracking
- Structured CSV data collection
- Exploratory Python analysis
- Reproducible documentation and reporting

## Technology
Python · pandas · matplotlib · CSV · Markdown

## Repository contents
- `analysis.py` — reproducible exploratory analysis
- `data/sample_observations.csv` — illustrative reconstructed dataset
- `docs/METHODOLOGY.md` — field-study design
- `docs/ARCHITECTURE.md` — research/data workflow diagram
- `docs/REPORT.md` — portfolio research report
- `docs/DATA_DICTIONARY.md` — variable definitions
- `requirements.txt` — Python dependencies

## Run the analysis
```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python analysis.py
```

The script summarises the sample dataset and saves analysis outputs to `outputs/`.

## Data note
The included dataset is **illustrative reconstructed portfolio data**, created to demonstrate the analysis workflow. It must not be cited as the original field dataset or as verified environmental measurements.
