Environmental data analysis

Aakkulam Lake Ecological Study

A reproducible portfolio study exploring urban-pressure indicators, water and habitat observations, and transparent statistical analysis.

Data integrity: the bundled observations are illustrative reconstructed portfolio data and are not presented as verified environmental measurements.

Analysis

Python, pandas, SciPy and matplotlib are used for cleaning, grouped summaries, bootstrap confidence intervals and Kruskal-Wallis tests.

Research workflow

Structured CSV observations, explicit missingness reporting, reproducible outputs and documented methodology.

Purpose

Demonstrates environmental research framing, data quality awareness, statistical reasoning and reproducible analysis.

Project source

The full analysis code, methodology, data dictionary and report are available in the GitHub repository.
