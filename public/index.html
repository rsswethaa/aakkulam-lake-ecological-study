Reproducible workflow

From raw observations to defensible analysis

The repository keeps the workflow explicit: structured CSV inputs, validation, grouped summaries, uncertainty-aware statistics and documented outputs.

01

Structure

Define site IDs, dates, numeric indicators, categorical pressure and observation notes.

02

Validate

Check missingness, data types, category values and out-of-range observations before analysis.

03

Analyse

Use pandas, SciPy and bootstrap summaries to compare ecological indicators across pressure groups.

04

Communicate

Separate descriptive evidence from inference and state limitations directly in the report.
